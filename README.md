This repository contains four internship projects focused on practical security and encryption tools, implemented in Python with simple GUIs for demonstration and learning:

Text Encryption — Multiple cipher implementations (RSA, AES, Caesar, XOR, Reverse) with a Tkinter GUI for encrypting/decrypting text. Includes key handling (RSA/AES) and Base64 output for easy copy/paste.

Image Encryption — Simple image encryption/decryption utilities that demonstrate symmetric encryption applied to image files and save/load encrypted images safely for analysis.

Password Analyzer — A Tkinter-based password-strength checker that evaluates length, character sets, and common weaknesses; provides visual feedback and recommendations to improve password security.

Keylogger (educational, in‑app only) — A safe, in‑application keystroke recorder that captures keys only while the app window is focused, for usability testing and security awareness. Contains explicit ethical guidance; does not run background/system-wide logging or transmit data.
